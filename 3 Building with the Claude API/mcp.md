# mcp

code "$HOME/Library/Application Support/Code/User/mcp.json"

here are the available MCP (Model Context Protocol) servers in your environment:

- mcp_azure_mcp_extension_azqr: Runs Azure Quick Review CLI (azqr) commands to generate compliance and security reports for Azure resources.
- mcp_azure_mcp_foundryextensions: Foundry Extensions service operations for Microsoft Foundry OpenAI, knowledge indexes, threads, agents, and resources.
- mcp_azure_mcp_subscription_list: Lists all Azure subscriptions for the current account.
- mcp_bicep_list_avm_metadata: Lists metadata for all Azure Verified Modules (AVM) - Microsoft's official, pre-built, tested, and maintained Bicep modules.
- mcp_azure_mcp_pricing: Azure Retail Pricing operations - Get Azure retail pricing for SKUs, services, regions and compare pricing.
- mcp_azure_mcp_servicebus: Service Bus operations – Commands to manage Azure Service Bus queues, topics, and subscriptions.
- mcp_azure_mcp_cloudarchitect: Cloud Architecture operations - Commands for generating Azure architecture designs and recommendations.
- mcp_azure_mcp_azureterraformbestpractices: Returns Terraform best practices for Azure.
